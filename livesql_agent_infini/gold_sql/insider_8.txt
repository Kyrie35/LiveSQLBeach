WITH EventDrivenTraders AS ( SELECT trdref AS tradereg, COUNT(*) AS total_transactions, SUM(CASE WHEN NOT sf.corpeventprx IS NULL THEN 1 ELSE 0 END) AS event_transactions FROM transactionrecord AS tr LEFT JOIN sentimentandfundamentals AS sf ON tr.transreg = sf.transref GROUP BY trdref HAVING CAST(SUM(CASE WHEN NOT sf.corpeventprx IS NULL THEN 1 ELSE 0 END) AS REAL) / COUNT(*) > 0.3 ), AggressiveSpeculators AS ( SELECT edt.tradereg FROM EventDrivenTraders AS edt JOIN trader AS t ON edt.tradereg = t.tradereg WHERE ( t.trading_performance -> '$.risklevel' ->> '$.risklevel' ) = 'Aggressive' ), VolatileSpeculators AS ( SELECT DISTINCT tr.trdref AS tradereg FROM transactionrecord AS tr JOIN sentimentandfundamentals AS sf ON tr.transreg = sf.transref JOIN AggressiveSpeculators AS ags ON tr.trdref = ags.tradereg WHERE ABS(sf.newsscore - sf.socscore) > 1.0 ), SpeculatorOMI AS ( SELECT vs.tradereg, tr.modfreq / NULLIF(1 - tr.cancelpct, 0) AS omi FROM transactionrecord AS tr JOIN VolatileSpeculators AS vs ON tr.trdref = vs.tradereg WHERE tr.cancelpct < 1 ) SELECT ROUND(AVG(omi), 4) AS average_omi_for_volatile_speculators FROM SpeculatorOMI LIMIT 100;
